# Characters (placeholder pixel art)

Generated by `tools/gen_player.py`; replace with hand-made sheets using the same layout at any time.

- `player.png` - 96x96 frames, facing right, one animation per row, max 6 columns.
- `player.json` - row order and frame counts: idle 4, run 6, jump 2, fall 2, dodge 4, light1 5, light2 5, heavy 6, skill 6, hurt 2, death 6.
- Feet rest on pixel row 88 of each frame (ground line); flip horizontally in code for left-facing.
- `_player_preview.png` - review sheet only.
