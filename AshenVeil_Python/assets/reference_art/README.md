# Ashen Veil — Visual Reference Art

These JPEG thumbnails are the user's reference screenshots for the game's intended visual direction. They are kept separate from runtime assets so the game does not accidentally load interface screenshots as scenery.

## Files

- `current_game_screenshot.jpg` — current prototype, for before/after comparison.
- `combat_reference_01.jpg` — target sword combat, enemy readability and hit feedback.
- `cathedral_gameplay_reference_02.jpg` — target HUD and gothic cathedral environment.
- `platforming_reference_03.jpg` — target platforming spaces and vertical level design.
- `ruined_bridge_reference_04.jpg` — target bridge traversal, ruins and combat staging.
- `combat_effects_reference_05.jpg` — target attack arcs and impact effects.
- `exploration_reference_07.jpg` — target interconnected castle exploration and enemy placement.
- `ashen_keep_reference_08.jpg` — target boss/arena mood and dark-fantasy palette.

The checked-in copies are compact 128×72 preview thumbnails to limit repository size; they are not intended to be used as the game's in-level art. They preserve the owner-provided images as visual notes. The game backgrounds remain under `../backgrounds/`.
