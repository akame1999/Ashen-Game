# Code Lyoko — Unity Prototype

This repository contains the game design documents and the first Unity movement prototype. The title is a working title; it refers to an existing franchise name, so select an original title before public/commercial release.

## Unity editor
- Editor version: `6000.6.7f1`
- Template: Universal 3D (URP)
- First milestone: isometric camera + player movement in a collision-bounded greybox arena.

## Prototype scene and movement
1. Open this repository as a Unity project using the editor version above.
2. Wait for scripts to compile.
3. Open `Assets/_Project/Scenes/Prototype_Scene.unity`.
4. Select **Tools → Code Lyoko → Setup Player Locomotion Animations** to add animation setup to an existing prototype scene; or **Tools → Code Lyoko → Create Prototype Scene** to rebuild the greybox scene.
5. Press Play and click the Game view. Use WASD or arrow keys to walk; hold Shift to run.
6. Check that the camera follows the player and the perimeter walls block movement.

## Animation architecture
- `Assets/_Project/Scripts/Player/IsometricPlayerController.cs`: camera-relative movement, facing direction, walk/run speed, gravity and collision.
- `Assets/_Project/Scripts/Player/PlayerLocomotionAnimator.cs`: smooths movement state into the Animator's `MoveSpeed` parameter.
- `Assets/_Project/Scripts/Camera/IsometricCameraFollow.cs`: orthographic isometric follow camera.
- `Assets/_Project/Editor/PrototypeSceneSetup.cs`: generates the greybox scene and an Animator Blend Tree.
- `Assets/_Project/Animations/`: generated by the editor tool with Idle, Walk and Run clips plus `Player_Locomotion.controller`.

The current capsule clips use subtle bob/squash motion to validate Animator wiring; they are intentionally placeholders, not finished humanoid walk/run cycles. Replace these clips after importing a rigged character and suitable licensed animations. Root motion is disabled so CharacterController movement remains authoritative.

## Repository hygiene
Commit `Assets/`, generated `.meta` files, `Packages/manifest.json`, `Packages/packages-lock.json`, and `ProjectSettings/`. Do not commit Unity's `Library/`, `Temp/`, `Logs/`, build outputs or local IDE files. Record sources and licences for generated or downloaded assets.
